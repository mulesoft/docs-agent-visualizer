= Governing Nodes

Node governance surfaces the security and compliance posture of each agent, broker, and Model Context Protocol (MCP) server in the agent network. View Flex Gateway protection and applied policies and follow links to API Manager to view policies.

[[viewing-node-policies]]
== View Node Policies

. Look for the shield icon on nodes to see which nodes are secured by Flex Gateways.
. Click the node to open the detail card and see the policies that are applied to the node.
. Click *View Policies* to view the policies for this instance in API Manager.
+
Policies are listed by category on the left and applied policies are listed on the right. 

[[adding-a-flex-gateway]]
== Add a Flex Gateway

. Click the node to open the detail card and see the policies that are applied to the node.
. Click *Add Flex Gateway*. 
. In API Manager, add an instance of the asset (MCP server, broker, or agent) to protect.
+
For information about adding an MCP server instance, see xref:flex-gateway::create-instance-task-mcp[]. For information adding an A2A instance, see xref:flex-gateway::create-instance-task-a2a[].
