= Agent Visualizer Overview

Agent Visualizer provides a detailed visual graph so you can see, understand, and interact with your enterprise's evolving network of agents, MCP Servers, and LLMs. Agent Visualizer gives you insight into hidden agent interactions, governance gaps, and performance bottlenecks. Agent Visualizer offers complete situational awareness of your agentic ecosystem. 

With Agent Visualizer, you can:

* Get a clear view of connections and interactions among all your agents, clients, and Model Context Protocol (MCP) servers.
* Understand data movement and dependencies at a glance by seeing which systems are calling your agents and what those agents are calling in turn.
* Detect potential issues proactively.
* Optimize agent orchestration for performance, trust, and scale. 

Agent Visualizer is an intuitive user interface that helps you:

 * Find blind spots in your agent network by showing all connected agents in one network map, with clear relationships and direction of calls, gaining complete situational awareness of your Agentic ecosystem. 
 * See unclear interaction patterns by showing realtime or historical transaction volume overlays on network edges. This helps you understand key pathways and identify under or overused connections. 
 * See governance gaps. You can see which agents are protected by Flex Gateways and policies. 
 * Understand node purpose and origin. You gain full understanding of each asset in your agent network and any active running instances when you select a node. 
 * Easily view product and non-production traffic. 
 
[[use-cases]]
== Use Cases

Use Agent Visualizer to gain clarity and control over your agent ecosystem.

* Understand inventory and dependencies
+
View a network graph of your enterprise agents to understand dependencies and troubleshoot failures. This provides the full inventory needed for system design and helps you avoid shadow IT.
* Validate agent consumption
+
Developers can validate how their agent is actually being consumed by viewing real-time transaction volume overlays.
* Assess security and compliance
+
Security and compliance personnel can visualize active policies in the agent network to validate coverage and instantly spot vulnerabilities.
* Troubleshoot failures
+
Developers can deep-link from the visualization directly into the underlying service logs for quick diagnostics

== Before You Begin

You must have these Anypoint Platform permissions to access Agent Visualizer:

* Anypoint Monitoring
* Monitoring: Monitoring Viewer
* Exchange Viewer
* API Manager View: View API Configuration, View Policies
