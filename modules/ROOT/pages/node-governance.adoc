= Node Governance

You can use the visual indicators on the graph to assess the security and compliance status of your agents.

== Identifying Policy-Protected Nodes

. Look for the shield icon within a node shape to see which nodes are secured by Flex Gateways.

== Reviewing Node Policies

. Select the node or edge to open the detail card, where policies appear as overlays or icons.

. Click the policy icon to view the policy details in API Manager.
