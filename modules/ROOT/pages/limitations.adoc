= Limitations of Agent Visualizer

Learn about the limitations of using Agent Visualizer.

== Limitations

* A maximum of 500 nodes is displayed on the agent graph. You can only select nodes that are visible on the canvas. If you don't see a node, use search to locate it.
* A maximum of 499 MCP tools are listed across MCP nodes.
