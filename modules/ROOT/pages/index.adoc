= Agent Visualizer Overview

Agent Visualizer provides a detailed visual graph so you can see, understand, and interact with your enterprise's evolving network of agents, MCP Servers, and LLMs. Agent Visualizer gives you insight into hidden agent interactions, governance gaps, and performance bottlenecks. Agent Visualizer offers complete situational awareness of your agentic ecosystem. 

With Agent Visualizer, you can:

* Get a clear view of connections and interactions among all your agents, clients, and Model Context Protocol (MCP) servers.
* Understand data movement and dependencies at a glance by seeing which systems are calling your agents and what those agents are calling in turn.
* Detect potential issues proactively.

Agent Visualizer is an intuitive user interface where you can:

* Explore your network
+
Zoom in and out, and move around the canvas to focus on specific areas of your graph.
*Filter your view
+
Narrow down the displayed data by environments or agent types to keep your network meaningful and avoid a "noisy blob". You can also toggle between views of production and non-production traffic.
* Access detailed information
+
Select any node or edge to open a detail panel (Inspector Panel). This panel surfaces a 360-degree view, including metadata like node type, name, domain, tags, last activity timestamp, and observability metrics such as the number of conversations, token burnout, and errors. 
For edges, you'll see metrics like conversation count, token consumption, and latency.
* Understand governance and security 
+
Visually identify nodes protected by Flex Gateways and see indications of policy violations. 
* Take action directly
+
From the Inspector Panel, you can access links to Runtime Manager for broker or MCP server logs, Anypoint Exchange, or API Manager for instance management and policies. 


[[before-you-begin]]
== Before You Begin

Access to Agent Visualizer requires these Anypoint Platform permissions:

* Anypoint Monitoring
* Monitoring: Monitoring Viewer
* Exchange Viewer
* API Manager View: View API Configuration, View Policies
